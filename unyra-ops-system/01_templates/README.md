# Templates

This layer governs UNYRA's protected master formats and separates template domains from fast drafting routes. Use it when the founder needs the right canonical format before any live file moves into CRM, operations, or compliance.

## Open first

| Priority | Surface | Founder use |
| --- | --- | --- |
| 1 | `OPEN-HERE.html` | Open the protected template portal before selecting any master format. |

## Protection note

| Protection | Required behavior |
| --- | --- |
| Master integrity | Do not use these masters as live transaction files. |
| Working-copy control | Duplicate the right master first and rename the working copy immediately. |
| Evidence placement | Move live working files into CRM, operations, or compliance as appropriate. |
| External language | Keep external language discipline inside `11_external-communications/`. |
| Closeout and retirement | Keep archive and retirement templates inside `08_closeout/` and `99_archive/`. |
| Source-layer boundary | Preserve this hub as the protected drafting source layer; live transaction evidence belongs in the accountable operating room, not in the master template library. |
