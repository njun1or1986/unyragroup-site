# Operations

This layer is the founder execution command center for UNYRA. It governs live movement, release authority, shipment funding, supplier coordination, packet custody, traceability handoff, temporary working files, and same-day intervention so execution cannot move faster than proof.

## Operations Control Posture

| Control Field | Current Standard | Founder Use |
| --- | --- | --- |
| Layer status | Active execution, movement, and proof-custody layer | Use this hub when a decision affects shipment movement, broker handoff, supplier payment, packet release, or operational custody. |
| Primary purpose | Connect active shipments, release gates, funding gates, document packets, supplier instructions, working files, and closeout proof. | Gives the founder one safe-movement map before execution widens. |
| Source rule | Update shipment rooms, release records, funding records, document-control packets, supplier packets, working files, and dashboards first, then refresh summary views. | Prevents operating confidence from outrunning source proof. |
| Decision rule | Do not treat packet completeness, supplier urgency, customer pressure, or commercial momentum as movement approval unless release, funding, executable-check, document, and containment records carry the same answer. | Keeps movement permission evidence-backed. |
| Protection rule | Keep working copies out of protected templates and route settled proof into governed custody. | Preserves approved masters while live execution matures. |

## Movement Permission Gates

| Gate | Pass Standard | If Not Passed |
| --- | --- | --- |
| Release gate | Pre-shipment release, executable-check board, scenario response, risk register, and shipment room carry the same current answer. | Hold broker handoff, forwarder release, and ETD-ready status. |
| Funding gate | Funding release, funding dashboard, cash outlook, release gate, packet proof, and executable-check record agree. | Hold supplier settlement, freight, broker, duty, clearance, or shipment-linked cash. |
| Packet gate | Document control, supplier packet, traceability, and shipment review are current and bounded. | Do not use clean-looking documents as movement authority. |
| Supplier response gate | Supplier receipt, document review, execution confirmation, trust posture, and supply resilience are current. | Keep supplier communication narrow and do not compress release decisions. |
| Traceability gate | Traceability room, document packet, compliance dashboard, claim/CAPA records, and shipment review support the same proof boundary. | Keep filing, challenge-defense, recovery, and FDA readiness confidence bounded. |
| Closeout gate | Shipment review, document control, task room, executable-check board, and archive route can reconstruct the final story. | Keep active custody and block archive finality. |

## Protection and Escalation Rules

| Trigger | Required Action | Founder Protection |
| --- | --- | --- |
| Packet completeness is used as release authority | Route back through pre-shipment release, executable-check board, and document control before action. | Separates proof from permission. |
| Funding, release, packet, scenario, or risk records diverge | Hold movement and run control-integrity review before widening. | Prevents same-day pressure from creating conflicting operating truth. |
| Supplier timing compresses the release window | Refresh supplier release packet, response escalation, and supply resilience before confirming wider action. | Prevents late supplier response from forcing rushed payment or broker decisions. |
| Traceability or compliance confidence widens while evidence gaps remain | Keep confidence bounded and refresh traceability, compliance, document control, and shipment review. | Protects challenge-defense and regulator credibility. |
| Temporary support files remain in working files after owner and destination are known | Move settled proof into shipment, document-control, compliance, CRM, dashboard, or archive custody. | Prevents hidden source of truth. |
| Closeout or archive is requested before proof is retrievable | Keep active custody and require shipment review plus archive closeout routing. | Stops archive finality from outrunning evidence. |
