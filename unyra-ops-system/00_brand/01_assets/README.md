# Assets

This layer governs UNYRA's approved brand assets and separates review-ready surfaces from protected source sets. Use it to understand what can be reviewed in branded HTML and what should remain in the controlled asset folders.

## Open first

| Priority | Surface | Founder use |
| --- | --- | --- |
| 1 | `OPEN-HERE.html` | Open the governed assets portal before reviewing signatures, compositions, or protected source folders. |

## Review surfaces

| Surface | Review purpose |
| --- | --- |
| `04_signatures/OPEN-HERE.html` | Approved email signatures and outbound identity closures. |
| `05_approved-compositions/OPEN-HERE.html` | Approved lockups, layout treatments, and reusable brand compositions. |

## Protected asset sets

| Source set | Protected contents |
| --- | --- |
| `01_logos/` | Primary logos, transparent marks, and SVG source files. |
| `02_icons/` | Approved app and icon assets. |
| `03_imagery/` | Governed brand illustration and still-life source visuals. |

## Founder routes

| Founder need | Route decision |
| --- | --- |
| Approved outbound signature | Enter through `04_signatures/OPEN-HERE.html`. |
| Approved lockup or layout | Enter through `05_approved-compositions/OPEN-HERE.html`. |
| Exact source file | Stay with the protected asset sets when source fidelity matters more than branded review surfaces. |

## Protection note

| Protection | Required behavior |
| --- | --- |
| Source-set authority | Do not create alternate approved assets outside the controlled source sets. |
| Asset custody | Keep logos, icons, and imagery authoritative in their protected folders. |
| Review-surface boundary | Use the branded asset memo and review surfaces for navigation, not as a replacement source of record. |
| Promotion control | Preserve approved lockups and seals exactly as exported; any visual change should start in the governed brand asset workflow before promotion. |
