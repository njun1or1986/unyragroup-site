# Brand Signatures Reference Memo

This reference surface keeps approved UNYRA signature treatments readable for founder review before any outbound email block, contact footer, or signature close is reused.

## Approved Signature Surfaces

| Approved surface | Controlled use |
| --- | --- |
| `unyra-business-development-signature-approved.png` | Business-development outbound signature treatment for institutional prospecting, supplier, and counterparty contact surfaces. |
| `unyra-founder-signature-newton-santos-approved.png` | Founder signature treatment for executive, founder-facing, and high-trust outbound contact surfaces. |

## Founder Uses

| Founder need | Required review |
| --- | --- |
| Signature selection | Validate which signature treatment should close founder-facing or business-development outbound. |
| Layout consistency | Keep hierarchy, spacing, role line, and contact stack consistent across institutional email use. |
| Reuse discipline | Confirm that signature reuse stays inside approved brand closure rules instead of improvised layouts. |
