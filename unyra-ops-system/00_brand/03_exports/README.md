# Exports

This layer is the founder-facing export hub for UNYRA's premium visual system. It connects Preview Docs, Domain Lanes, and the Visual Standard so outbound benchmarks and governed styling stay inside one brand-controlled surface.

## Open first

| Priority | Surface | Founder use |
| --- | --- | --- |
| 1 | `OPEN-HERE.html` | Open the governed export portal before moving into preview routing, domain lanes, or visual-standard custody. |

## Hub structure

| Surface | Governance role |
| --- | --- |
| `02_preview-docs/OPEN-HERE.html` | Generated preview-docs portal for fast benchmark review. |
| `02_preview-docs/index.html` | Full preview hub with founder pathways and domain lanes. |
| `01_visual-standard/OPEN-HERE.html` | Governed design and export standard for branded surfaces. |

## Founder routes

| Founder need | Route decision |
| --- | --- |
| Fast benchmark review | Enter through `02_preview-docs/OPEN-HERE.html`. |
| Full library by operating theme | Use `02_preview-docs/index.html` for the domain-lane view. |
| Styling governance | Move into `01_visual-standard/OPEN-HERE.html` when the founder needs the governing discipline behind branded surfaces. |

## Protection note

| Protection | Required behavior |
| --- | --- |
| Benchmark route | Exports is the governed benchmark route, not a loose generated-output folder. |
