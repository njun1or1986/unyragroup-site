Normalization Rules

How this stays honest

This scorecard uses the same review window across all categories, favors quality ratios over raw activity, marks incomplete data as provisional, and refuses to claim improvement when the source layer is stale.

Judgment is allowed, but only when anchored to the underlying dashboard or source record.

Main Watchpoint

What matters most right now

UNYRA is becoming more governable and more structured. The main unresolved question is whether commercial momentum will now be matched by cash discipline, protected margin quality, dependable counterparty response behavior, and proof-grade executable-check closure on trust-linked matters.

How To Use This

What this scorecard is for

This is not a replacement for the dashboards underneath it. It is the founder's normalized lens for deciding whether the system is producing healthy business behavior, not just a high volume of activity, chasing, or weakly proved overrides.

Use it to decide where founder pressure should rise, where discipline is holding, and when growth quality is becoming more believable.
