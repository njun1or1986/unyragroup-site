Founder Use Rule

Why this matrix matters

This layer is where UNYRA stops describing trust problems and starts governing them. A counterparty can still be commercially important, but that importance does not justify normal release confidence when response behavior is weak.

The matrix creates one institutional answer for what trust should change in release, growth, sourcing, and escalation before the next decision goes out.
