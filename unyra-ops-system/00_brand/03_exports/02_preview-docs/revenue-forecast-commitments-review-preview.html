How To Use This

What this forecast is for

This layer is not a replacement for the sales pipeline board. It is the founder's disciplined view of what revenue is committed, what is likely, what is only weighted, and what should still be treated as stretch.

Use it to decide where commercial pressure should rise, where forecast confidence is overstated, and when quarterly targets need a more honest revenue base.
