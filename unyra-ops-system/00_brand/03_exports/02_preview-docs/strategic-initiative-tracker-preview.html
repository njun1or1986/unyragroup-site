Critical Dependency

What can slow the portfolio down

Strategic work often fades because it sits in review notes but not in a named initiative with ownership. This tracker exists to keep the founder's monthly direction alive through weekly execution pressure, especially when the hardest discipline is not commercial ambition but owner behavior at sensitive live gates.

Portfolio Rule

What belongs here

Use this tracker only for cross-functional priorities that span more than one week or more than one function. If it can be closed in a single cycle, it probably belongs in a weekly review or founder decision register instead. If it changes whether the business still needs founder rescue every week, it belongs here.
