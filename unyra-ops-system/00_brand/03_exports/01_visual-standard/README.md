This layer governs the visual discipline behind UNYRA's preview docs, branded memos, folder portals, and founder-facing export surfaces. It holds the styling system that keeps premium internal documents aligned before any benchmark, template, or dashboard surface is promoted.

| Scope | Standard controlled |

## Protection note

| Protection | Required behavior |
| --- | --- |
| Style promotion | Govern presentation here before promoting styling changes across the system. |
| Record boundary | Do not place live operational records in this layer. |
| Custody discipline | Keep stylesheet custody, preview behavior, and founder-facing document chrome tied to this governed standard before changes propagate across exports. |
