# UNYRA Visual Identity

| Identity Control | Current Standard |
| --- | --- |
| Status | Active visual identity standard |
| Purpose | Protect UNYRA's premium, minimalist, corporate, and globally credible visual identity across documents, dashboards, previews, signatures, covers, icons, and future export surfaces. |
| Source rule | Use the approved palette, approved asset inventory, approved composition priority, premium document standard, and exported visual standard before changing any visual treatment. |
| Decision rule | Prefer restrained approved compositions, spacing, typography, and navy/gold hierarchy over decorative redesign or improvised brand marks. |
| Asset protection | Do not redraw, stretch, recolor, restyle, replace, or reinterpret approved logos, seals, signatures, imagery, or lockups unless a new approval is explicitly given. |

## Approved Direction

UNYRA's visual identity is premium, minimalist, corporate, and globally credible.

| Direction | Required signal |
| --- | --- |
| Premium | The identity should feel refined, intentional, and suitable for high-trust business communication. |
| Minimalist | The system should rely on proportion, spacing, and restraint instead of decoration. |
| Corporate | The visual language should support procurement, compliance, finance, and executive review. |
| Globally credible | The identity should feel appropriate for international trade, cross-border logistics, and institutional counterparties. |

It should feel suitable for international trade, procurement, compliance, and executive communication.

## Core Palette

| Color role | Value | Primary use |
| --- | --- | --- |
| Primary navy | `#08121E` | Titles, structure, authority, and high-confidence document framing. |
| Support navy | `#102436` | Secondary framing, deep panels, and controlled contrast. |
| Gold accent | `#C2A071` | Premium accents, highlights, rules, and executive emphasis. |
| Strong gold accent | `#9D7646` | Darker accent text or restrained luxury detail. |
| Ivory | `#F7F3EC` | Soft premium surfaces and warm document backgrounds. |
| Canvas | `#F3EEE6` | Neutral page canvas and quiet contrast fields. |
| Muted support | `#5B6672` | Supporting metadata, secondary copy, and low-emphasis labels. |
| Muted dark | `#2A3742` | Body text, table detail, and secondary authority. |

## Style Rules

| Style rule | Required behavior |
| --- | --- |
| Dark navy authority | Use dark navy for titles, structure, and authority. |
| Restrained gold | Use gold sparingly for emphasis, accents, and executive polish. |
| Neutral backgrounds | Keep backgrounds neutral and clean. |
| Spacing and typography | Maintain generous spacing and restrained typography. |
| Avoid visual noise | Avoid loud color combinations, excessive gradients, and clutter. |

## Internal Document Guidance

| Guidance | Required behavior |
| --- | --- |
| Mastheads | Keep mastheads small and elegant. |
| Alignment and whitespace | Use premium alignment and whitespace. |
| Rules and tables | Prefer subtle rules and simple tables over heavy boxes. |
| Future-ready dashboards and forms | Format internal dashboards and forms so they can later be elevated into branded client-ready materials without redesigning the structure. |
| Document standard alignment | Apply `00_brand/02_guidelines/UNYRA-Premium-Document-Standard.md` for visual previews, exports, and future PDF-ready operating materials. |
