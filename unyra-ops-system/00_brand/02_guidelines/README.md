# Brand Guidelines

This layer holds the written rule set behind UNYRA's identity, premium document standard, and institutional voice discipline. It is the brand-governance surface to read before moving into Visual Standard, Preview Docs, or founder-facing export benchmarks.

## Open first

| Priority | Surface | Founder use |
| --- | --- | --- |
| 1 | `OPEN-HERE.html` | Open the governed brand-guidelines portal before moving into assets, visual standards, previews, or export benchmarks. |

## Guidance standards

| Standard | Governs |
| --- | --- |
| `UNYRA-Visual-Identity.md` | Identity posture, tone, and visual character. |
| `UNYRA-Premium-Document-Standard.md` | Document structure, presentation rules, and founder-facing polish. |
| `UNYRA-Institutional-Communication-Style-Guide.md` | Writing discipline across external counterparties and controlled outbound language. |

## Governance routes

| Route | Use when |
| --- | --- |
| `../01_assets/OPEN-HERE.html` | The founder needs the approved identity asset layer behind these rules. |
| `../03_exports/01_visual-standard/OPEN-HERE.html` | The founder needs the live visual-governance surface. |
| `../03_exports/OPEN-HERE.html` | The founder needs the export hub that connects these rules to preview routing. |
| `../03_exports/02_preview-docs/OPEN-HERE.html` | The founder needs the benchmark surface where these rules become founder-facing examples. |

## Founder use

| Founder need | Route decision |
| --- | --- |
| Rule set | Stay in `Brand Guidelines` when the founder needs the governing language itself. |
| Approved marks | Move into `Assets` when the founder needs the approved marks and compositions governed by these rules. |
| Styling system | Move into `Visual Standard` when the founder wants the governed styling system behind the rules. |
| Live expression | Move into `Exports` or `Preview Docs` when the founder wants to see those rules expressed as live branded surfaces. |

## Protection note

| Protection | Required behavior |
| --- | --- |
| Governance language | Use this layer when the founder needs controlled brand rules, not just approved assets or export outputs. |
| Change seriousness | Do not treat guidance edits as cosmetic copy changes; they govern how assets, documents, previews, and outbound language should be promoted. |
| Propagation control | Keep identity, document-standard, and communication-rule changes aligned here before they propagate into exports or founder-facing benchmark surfaces. |
