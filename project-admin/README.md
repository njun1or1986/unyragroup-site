# Unyra Website Project Admin

Este diretorio concentra a camada administrativa do website da Unyra Group LLC.

Use este espaco para:

- localizar rapidamente o estado atual do projeto
- restaurar checkpoints aprovados
- entender qual projeto Vercel serve o dominio oficial
- separar historico, legado e operacao do codigo ativo

## Leitura rapida

- `PROJECT-STRUCTURE.md`
- `DEPLOYMENT-AND-DOMAINS.md`
- `RESTORE-AND-CHECKPOINTS.md`
- `LIVE-STATUS-2026-05-09.md`
- `checkpoints/UNYRA-OFFICIAL-ORGANIZED-BASE-2026-05-09.md`

## Subpastas

- `checkpoints/`: memorias de marcos aprovados
- `scripts/`: scripts de restauracao
- `archive/`: material legado ou itens fora do runtime atual

## Observacao importante

O codigo ativo do site continua na raiz do projeto, especialmente em:

- `app/`
- `components/`
- `lib/`
- `messages/`
- `public/`
