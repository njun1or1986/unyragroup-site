# Page Blueprints

## Use This File

Use these blueprints when the user asks for a site from scratch and the repo or brief does not already define the information architecture.

Start with one blueprint, then adapt it to the brand and offer. Do not ship these structures mechanically.

## 1. Premium Homepage

Recommended flow:

1. Hero with thesis, supporting line, and primary CTA
2. Brand or proof strip
3. Core value proposition in 3 beats
4. Signature feature or capability spotlight
5. Immersive story section with image/video/background treatment
6. Testimonials, case study, or proof block
7. Comparison, differentiator, or objection-handling section
8. Final CTA
9. Minimal but polished footer

Use this when the site needs a flagship page that introduces the brand and drives a single main conversion path.

## 2. Product Launch Page

Recommended flow:

1. Hero with launch message and pre-order/sign-up CTA
2. Product reveal visual
3. Why it matters now
4. Key product pillars
5. Short demo or feature sequence
6. Specs or detail section
7. Early proof, quotes, or waitlist momentum
8. Final conversion close

Use this when the page is about one product, one moment, and one action.

## 3. Premium Service Company Site

Recommended flow:

1. Hero with positioning and CTA
2. Who it is for
3. Services overview
4. Selected outcomes or case studies
5. Process
6. Differentiators
7. Team or philosophy
8. Contact/consultation CTA

Use this when the brand sells expertise, retainers, or high-trust services.

## 4. Multi-Section Product Story Page

Recommended flow:

1. Hero thesis
2. Problem framing
3. Product mechanism
4. Feature story 1
5. Feature story 2
6. Feature story 3
7. Ecosystem or integration section
8. Proof
9. Pricing or CTA close

Use this when the user wants an Apple-style narrative product page that reveals the value over scroll depth.

## 5. Minimal Landing Page

Recommended flow:

1. Sharp headline and CTA
2. One visual or product frame
3. Three concise reasons to care
4. One proof block
5. Closing CTA

Use this when speed, clarity, and conversion matter more than a broad story.

## Blueprint Adaptation Rules

- Collapse sections if the offer is simple.
- Split sections if the product or service has multiple conceptual layers.
- Give the strongest proof earlier when trust is the main conversion barrier.
- Move pricing later when narrative understanding is required first.
- Move pricing earlier when qualification is more important than persuasion.
- If the brand has exceptional visuals, allow longer immersive moments.
- If the brand lacks visuals, strengthen typography, layout, and proof instead.
