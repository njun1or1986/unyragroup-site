# WordPress Theme Resources

Este diretorio concentra a conversao do website da Unyra para WordPress.

## Conteudo atual

- `unyra-group-corporate/`
  tema WordPress fonte
- `unyra-group-corporate-theme.zip`
  pacote pronto para upload no WordPress

## Uso recomendado

Use esta pasta quando a demanda envolver:

- instalacao em WordPress
- manutencao do tema convertido
- entrega alternativa fora da stack Next.js
